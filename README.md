# คำนวณต้นทุนสินค้า

เว็บแอปคำนวณต้นทุนต่อชิ้น ราคาขายแนะนำ กำไร และจุดคุ้มทุน — HTML/CSS/JS ล้วน ไม่ต้อง build ไม่มี backend

## ฟีเจอร์
- กรอกวัตถุดิบ / ค่าแรง ต่อ 1 ล็อต → หารเป็นต่อชิ้นอัตโนมัติ
- ต้นทุนผันแปรต่อชิ้น (แพ็กเกจ ค่าส่ง) และค่าใช้จ่ายคงที่ต่อเดือน (เฉลี่ยตามยอดผลิต)
- ราคาขายแนะนำจาก % กำไรเป้าหมาย + % ค่าธรรมเนียมแพลตฟอร์ม
- กำไร/ชิ้น, Margin, Markup, จุดคุ้มทุนต่อเดือน, กำไรต่อเดือน
- เก็บได้หลายสินค้า บันทึกอัตโนมัติใน localStorage
- ส่งออก CSV (เปิดใน Excel ได้ภาษาไทย), สำรอง/นำเข้า JSON, พิมพ์
- ใช้บนมือถือได้: แถบสรุปติดขอบล่างจอ, คีย์บอร์ดตัวเลข, เพิ่มลงหน้าจอโฮมได้เหมือนแอป, ใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## สูตรที่ใช้
- ต้นทุน/ชิ้น = (วัตถุดิบ + ค่าแรง) ÷ ชิ้นต่อล็อต + ผันแปรอื่น + ค่าคงที่ ÷ ยอดต่อเดือน
- ราคาแนะนำ = ต้นทุน ÷ (1 − %กำไร − %ค่าธรรมเนียม)
- จุดคุ้มทุน = ค่าคงที่ต่อเดือน ÷ (ราคา − ค่าธรรมเนียม − ต้นทุนผันแปร/ชิ้น)

## Deploy ขึ้น GitHub Pages (ฟรี)
1. github.com → **New repository** → ตั้งชื่อ เช่น `cost-calculator` → เลือก **Public** → Create
2. **Add file → Upload files** → ลากไฟล์ทั้งหมด*ในโฟลเดอร์นี้* (ไม่ใช่ตัวโฟลเดอร์) → **Commit changes**
   (ไฟล์ `.nojekyll` เป็นไฟล์ซ่อน ถ้าลากไม่ติดมาก็ไม่เป็นไร)
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/cost-calculator/`

## เพิ่มลงหน้าจอโฮมมือถือ
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป** / **เพิ่มลงในหน้าจอหลัก**

## Deploy ขึ้น Netlify (ทางเลือก)

**วิธีที่ 1 — ลากวาง (เร็วสุด)**
1. ไปที่ https://app.netlify.com/drop
2. ลากโฟลเดอร์ `cost-calculator` ทั้งโฟลเดอร์ไปวาง → ได้ลิงก์ทันที

**วิธีที่ 2 — ผ่าน GitHub (อัปเดตอัตโนมัติทุกครั้งที่ push)**
1. push โฟลเดอร์นี้ขึ้น GitHub repo
2. Netlify → Add new site → Import from Git → เลือก repo
3. Build command: เว้นว่าง · Publish directory: `.` (มีใน `netlify.toml` แล้ว)

**วิธีที่ 3 — Netlify CLI**
```bash
npm i -g netlify-cli
cd cost-calculator
netlify deploy --prod
```
