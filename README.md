# คุ้มครัว · คำนวณต้นทุนร้านอาหารและเครื่องดื่ม

เว็บแอปสำหรับร้านอาหาร/คาเฟ่ ใช้บนมือถือได้เหมือนแอป — HTML/CSS/JS ล้วน ไม่ต้อง build ไม่มี backend ข้อมูลเก็บในเครื่องผู้ใช้

เว็บจริง: https://chalongrath-kodsriwong.github.io/cost-calculator/

## ฟีเจอร์
- **คลังวัตถุดิบ** — ของฉัน + รายการพื้นฐาน 150+ รายการ แบ่งหมวด กรอกจำนวนที่ซื้อกับราคารวม ระบบคิดราคาต่อหน่วยให้
- **ส่วนที่ใช้ได้จริง (Yield %)** — คิดส่วนสูญเสียจากการตัดแต่ง
- **แปลงหน่วยอัตโนมัติ** — ซื้อเป็น กก./ลิตร ใช้เป็น กรัม/ช้อนชา/ช้อนโต๊ะ/ถ้วยตวง
- **ประวัติราคา** — แก้ราคาวัตถุดิบครั้งเดียว ต้นทุนทุกเมนูอัปเดตเอง มีกราฟขึ้น-ลง
- **เมนูหลายไซซ์** (S/M/L) คัดลอกสูตรไปปรับต่อได้
- **ต้นทุนต่อจาน** — วัตถุดิบ + บรรจุภัณฑ์ + แก๊ส (คิดตามนาทีที่ใช้เตา) + ค่าแรง + อื่นๆ
- **ตั้งราคา** — ลาก Food Cost % ได้ราคาแนะนำ ปัดเลขสวย (ลงท้าย 0/5/9)
- **ราคาเดลิเวอรี่** — คิด GP + VAT แยกทุกแพลตฟอร์ม ให้กำไรไม่น้อยกว่าหน้าร้าน
- **จุดคุ้มทุน** — ค่าใช้จ่ายประจำเดือน + เป้ากำไรสุทธิ → ยอดขายต่อเดือน/ต่อวัน/จานต่อวัน
- **SOP สูตรมาตรฐาน** — มีรูป วัตถุดิบ ขั้นตอน บันทึกเป็นรูปแชร์หรือพิมพ์ได้
- **บัญชีรายรับรายจ่าย** — บันทึกยอดขายจากเมนู (หัก GP ตามช่องทางให้อัตโนมัติ), รายรับอื่น, รายจ่ายตามหมวด; สรุปรายเดือน กราฟรายวัน เทียบเป้าจุดคุ้มทุน ส่งออก CSV
- **ซื้อวัตถุดิบ = อัปเดตราคา** — ลงรายจ่ายซื้อวัตถุดิบพร้อมจำนวน ราคาในคลังและต้นทุนเมนูอัปเดตให้
- **แดชบอร์ด** — Food Cost เฉลี่ย, ต้นทุน/กำไรเฉลี่ย, เมนูที่ควรปรับราคา
- สำรอง/นำเข้าข้อมูล (JSON), ส่งออกตารางเมนู (CSV), ใช้ออฟไลน์ได้

## สูตร
- ราคา/หน่วยฐาน = ราคารวม ÷ (จำนวนที่ซื้อ × ตัวคูณหน่วย) ÷ Yield%
- ราคาหน้าร้านแนะนำ = ต้นทุนวัตถุดิบต่อจาน ÷ Food Cost% เป้าหมาย
- ราคาเดลิเวอรี่ = ราคาหน้าร้าน ÷ (1 − GP% × (1 + VAT%))
- ยอดขายที่ต้องได้/เดือน = ค่าใช้จ่ายคงที่ ÷ (1 − ต้นทุนผันแปร% − กำไรเป้าหมาย%)
